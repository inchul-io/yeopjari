# 옆자리

동료들이 픽셀 캐릭터가 되어 바탕화면 아래쪽을 총총 걸어다니는 **사내 메신저** (Windows)

- 말풍선 메시지 · 입력 중 표시 · 접속/자리비움/오프라인 상태
- 동료에게 인사하기, 물건 던지기 (💩 ⚾ 🐤 💖 🍌 ❄️ 🍙 ⭐)
- 캐릭터 15종 × 14색
- 그룹 코드로 초대 · 메시지는 그룹 코드로 암호화
- **자동 업데이트** (한 번 설치하면 이후 버전은 자동 적용)

## 설치

1. [Releases](../../releases/latest)에서 `Yeop-x.x.x-win64.zip` 다운로드
2. zip 우클릭 → 속성 → **[차단 해제]** 체크 → 확인 (보안 경고창 방지)
3. 압축 풀기 → `install.bat` 실행
4. 이름·캐릭터 고르고, 그룹 코드 만들기(또는 받은 코드 입력)

## 사용법

| 동작 | 방법 |
|---|---|
| 메시지 쓰기 | 캐릭터 클릭 또는 `Ctrl+Alt+Space` |
| 인사하기 | 동료 캐릭터 더블클릭 |
| 물건 던지기 | 동료 캐릭터 우클릭 |
| 숨기기/보이기 | `Ctrl+Alt+H` |
| 설정·조용히 모드·업데이트 확인 | 트레이 아이콘 우클릭 |

## 저장소 구조 (관리자용)

- `manifest.json` : 최신 버전 정보 + 파일 목록(SHA-256). 앱이 3시간마다 확인
- `app/` : 앱 본체 파일. 새 버전이면 바뀐 파일을 받아 교체 후 재시작
- `tools/publish.py` : `python3 tools/publish.py <앱폴더> . "업데이트 메모"` 로 위 두 개를 생성
